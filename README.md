# 🐑 مزرعتي - Mozraaty

## نظرة عامة

**مزرعتي** هو تطبيق ويب متكامل وحديث مصمم خصيصاً لإدارة مشاريع تربية الأغنام. يجمع بين إدارة القطيع والعمليات المالية والتقارير الشاملة في منصة واحدة سهلة الاستخدام.

### المبدأ الأساسي

التطبيق يدير المشروع **كاملاً** وليس كل رأس على حدة:
- 🐑 **القطيع ككل** - تتبع العدد الإجمالي
- 💰 **الأموال ككاملة** - تحسب الأرباح على مستوى المشروع
- 📈 **النمو المستمر** - من 10 رؤوس إلى ما لا نهاية

## الميزات الرئيسية

### 📊 لوحة التحكم الذكية
- رسالات ترحيبية ديناميكية
- إحصائيات فورية للقطيع والمال
- رسوم بيانية لنمو المشروع
- سجل العمليات الأخيرة

### 🐑 إدارة القطيع
- **الشراء**: تسجيل عمليات شراء مع تفاصيل كاملة
- **الولادات**: تسجيل المواليد (ذكور/إناث)
- **المبيعات**: تسجيل عمليات البيع برسوم كاملة
- **النفوق**: تسجيل حالات الوفيات مع الأسباب

### 💰 الإدارة المالية
- **تتبع رأس المال**: المبلغ الأولي المستثمر
- **المصاريف**: 14 فئة مصروف مختلفة
- **الحسابات الدقيقة**: تمييز بين الرصيد النقدي وقيمة القطيع
- **النتائج المالية**: حساب الأرباح والخسائر

### 📈 التقارير والإحصائيات
- **تقرير القطيع**: أعداد وتغييرات
- **التقرير المالي**: دخل ومصاريف
- **التفصيل الشهري**: مقارنات بين الأشهر
- **رسوم بيانية**: تصور واضح للبيانات

### 🌾 إدارة العلف
- تتبع أنواع العلف المختلفة
- حساب المخزون والاستهلاك
- تكاليف العلف الكاملة

## الجداول الأساسية

### Projects (المشاريع)
```sql
id, name, description, start_date, initial_capital, initial_flock_size, currency
```

### Flocks (القطيع)
```sql
id, project_id, current_count, total_births, total_purchases, total_sales, total_deaths
```

### Transactions (العمليات)
```sql
id, project_id, type, amount, quantity, description, category, transaction_date, notes
```

### Purchases/Births/Sales/Deaths (تفاصيل العمليات)
جداول منفصلة لكل نوع عملية بتفاصيل إضافية

### Feed Types (أنواع العلف)
```sql
id, project_id, name, unit, current_stock, unit_price, total_cost
```

## التكنولوجيا المستخدمة

- **Frontend**: Next.js 14 + React 18 + TypeScript
- **Styling**: Tailwind CSS + Custom CSS
- **Charts**: Chart.js + React Charts
- **Database**: PostgreSQL
- **State Management**: Zustand
- **API**: Next.js API Routes
- **Notifications**: React Hot Toast

## البدء السريع

### 1. المتطلبات
- Node.js 18+
- PostgreSQL 12+
- npm أو yarn

### 2. التثبيت
```bash
git clone https://github.com/16mouaad05-cloud/mozraaty.git
cd mozraaty
npm install
```

### 3. إعداد قاعدة البيانات
```bash
npm run db:init
npm run db:seed
```

### 4. التشغيل
```bash
cp .env.example .env.local
npm run dev
```

### 5. الوصول
افتح [http://localhost:3000](http://localhost:3000)

## الحسابات الرياضية

### 1. عدد القطيع
```
العدد الحالي = البداية + المشتريات + الولادات - المبيعات - النفوق
```

### 2. الرصيد النقدي
```
الرصيد = رأس المال + المبيعات - الشراء - المصاريف
```

### 3. قيمة القطيع
```
القيمة = العدد الحالي × السعر المتوسط للرأس
```

### 4. النتيجة النهائية
```
النتيجة = الرصيد النقدي + قيمة القطيع - رأس المال الأولي
```

## دليل الاستخدام

### تسجيل عملية شراء
1. اذهب إلى "الشراء"
2. اضغط "+ شراء جديد"
3. أدخل التفاصيل
4. سيزداد عدد الأغنام تلقائياً ✅

### تسجيل ولادة
1. اذهب إلى "الولادات"
2. اضغط "+ تسجيل ولادة"
3. أدخل عدد المواليد
4. سيزداد العدد بدون مصاريف ✅

### تسجيل مصروف
1. اذهب إلى "المصاريف"
2. اضغط "+ مصروف جديد"
3. اختر الفئة والمبلغ
4. سيتم خصمه من الرصيد تلقائياً ✅
