# 🐑 مزرعتي - Mozraaty

تطبيق ويب متكامل وحديث لإدارة مشروع تربية الأغنام

## المميزات الرئيسية

### 🐑 إدارة القطيع
- متابعة عدد الأغنام الحالي
- تسجيل عمليات الشراء والبيع
- تسجيل الولادات والنفوق
- حساب تلقائي لعدد القطيع

### 💰 إدارة الأموال
- تتبع رأس المال
- تسجيل المصاريف بفئات متعددة
- حساب المبيعات والمشتريات
- عرض الرصيد المالي والنتيجة

### 📊 التقارير والإحصائيات
- تقارير القطيع الشهرية والسنوية
- تقارير مالية تفصيلية
- رسوم بيانية لنمو المشروع
- سجل العمليات الكامل

### 🌾 إدارة المخزون
- تتبع العلف والمواد الغذائية
- حساب الاستهلاك والمتبقي
- تنبيهات عند انخفاض المخزون

## البدء السريع

### المتطلبات
- Node.js 18+
- PostgreSQL 12+
- npm أو yarn

### التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/16mouaad05-cloud/mozraaty.git
cd mozraaty

# تثبيت المكتبات
npm install

# إعداد متغيرات البيئة
cp .env.example .env.local

# تهيئة قاعدة البيانات
npm run db:init

# إضافة البيانات الأولية
npm run db:seed

# تشغيل التطبيق
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000) في متصفحك.
